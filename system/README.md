# 日和 回収管理システム

## 起動

Mac で `start-mac.command` をダブルクリックします。Ollama モデル名の入力は、未設定の場合そのまま Enter を押してください。ターミナル画面は開いたままにします。Node.js 22.13 以降が必要です。

| 画面 | URL | ユーザー名 | パスワード |
| --- | --- | --- | --- |
| お客様 | http://127.0.0.1:4173/customer | 不要 | 不要 |
| 管理者 | http://127.0.0.1:4173/admin/ | admin | 123456 |
| スタッフ a | http://127.0.0.1:4173/employee/ | employee | abcdef |

上記はローカル版の初回ログイン情報です。初回ログイン時にアカウントをデータベースへ登録します。以後の変更は「アカウント管理」で行います。起動ファイルの値を変更しても、登録済みパスワードは変わりません。

## 操作

1. 管理者画面の「顧客管理」で顧客を登録します。
2. お客様画面で氏名・電話番号・回収品・住所・希望日時を入力し、申し込みます。
3. 管理者画面を更新し、オーダーの「詳細」で担当スタッフ a を割り当てます。
4. スタッフ画面で担当オーダーを確認し、「回収を開始」、作業後に「回収完了にする」を押します。
5. 管理者画面で完了状態を確認します。

日本語の依頼文から回収品・住所・希望日時を抽出できます。初期設定はルール抽出です。Ollama を起動し、導入済みモデル名を指定するとモデル抽出に切り替わります。抽出後は内容を確認し、希望日時を指定してください。

## ファイル

- `customer.html` — お客様画面
- `admin.html` — 管理者画面の構成
- `employee.html` — スタッフ画面
- `ui/style.css` — 色・書体・配置
- `ui/customer.js`、`ui/staff.js`、`ui/employee.js` — 各画面の動作
- `worker/index.js` — 保存処理・権限確認・情報抽出
- `hiyori.sqlite` — 起動後に作成されるデータベース

HTML は起動中のサーバーを通して表示します。管理画面の注文一覧などは JavaScript で生成します。HTML・CSS・画面用 JavaScript の変更は、保存後にブラウザーを更新すると反映されます。

停止はターミナルで Control+C。登録内容は再起動後も保存されます。実機のスマートフォンや別のパソコンから接続する場合は、別途サーバーの公開設定が必要です。

## 確認用の操作例

1. 管理者でログインし、「顧客管理」→「顧客を追加」を押します。氏名を「山田 花子」、電話番号を「090-0000-0020」として登録します。
2. 別のタブでお客様画面を開き、同じ氏名・電話番号を入力します。
3. 「日本語の依頼文から情報を抽出」を開き、下記の依頼文を入力して「内容を抽出する」を押します。

   > 11月25日10時に冷蔵庫1台と洗濯機1台を回収してください。東京都新宿区西新宿2-8-1

4. 回収品と住所に値が入ったことを確認します。抽出された希望日時を確認し、日時入力欄で対応する日付・時刻を選びます。必要に応じて内容を修正し、「申し込む」を押します。表示された受付番号を控えます。
5. 管理者画面を更新します。受付番号に対応するオーダーの「詳細」を開き、担当スタッフを「a」にして「変更を保存」を押します。状態は「回収予定」になります。
6. 別のタブでスタッフ画面を開き、employee / abcdef でログインします。スタッフ a に割り当てられたオーダーだけが表示されます。
7. 「回収を開始」を押すと「回収中」、続いて「回収完了にする」を押すと「回収完了」になります。
8. 管理者画面を更新し、同じ受付番号の状態を確認します。

## 情報抽出の対応範囲

初期設定は、物品名・住所・日時の表記を規則に照らして抽出する方式です。文章を変更しても規則に一致すれば抽出できますが、自由な会話全般への対応は確認できていません。

対象の物品名は、冷蔵庫、洗濯機、テレビ、ソファ、ベッド、テーブル、椅子、電子レンジ、自転車、エアコン、棚、パソコンです。住所は都道府県を含む表記、日時は「11月25日10時」などの表記を想定しています。「来週の水曜日」「前に相談した家電」のような相対日時や文脈を必要とする内容は、手動で確認・入力してください。希望日時は抽出後も日時入力欄で選択します。

モデルによる抽出は別途設定が必要です。Cloudflare Workers AI の実モデルで、回収品・住所・希望日時の抽出を確認しています。公開環境ではモデル抽出、ローカルの初期設定ではルール抽出を使用します。表現によって誤抽出があり得るため、登録前に内容を確認してください。

### Ollama を使用する場合

1. Ollama をインストールして起動し、日本語を扱えるモデルを導入します。
2. ターミナルで `ollama list` を実行し、導入済みモデル名を確認します。
3. 本システムを停止して再起動します。Ollama モデル名の入力欄に、確認したモデル名を入力します。
4. お客様画面から依頼文を抽出し、「モデル抽出」と表示されることを確認します。物品・住所・希望日時を原文と照合してください。
5. 接続エラーが表示された場合は、Ollama の起動状態とモデル名を確認します。モデルを使用しない場合は再起動時にモデル名を空欄にします。

## データの確認

プロジェクトのフォルダーでターミナルを開き、`sqlite3 -readonly hiyori.sqlite` を実行します。続けて以下を入力すると、保存済みオーダーを確認できます。

```sql
.headers on
.mode column
SELECT id, items, appointment, staff, status FROM orders;
.quit
```

ページが開かない場合は、起動用ターミナルが実行中か確認してください。管理者・スタッフ画面では、URL末尾の `/` まで正しく入力します。`Not found` が表示される場合は、最新版のフォルダーから起動しているか確認してください。

## アカウント管理

管理者画面の左メニューで「アカウント管理」を開きます。

- **パスワード変更** — 対象者の行で「パスワード変更」を押し、新しいパスワードを2回入力します。6文字以上で設定できます。自分のパスワードを変更するとログイン画面に戻ります。
- **スタッフ追加** — 「アカウント追加」で権限を「スタッフ」にし、ユーザー名・スタッフID・パスワードを入力します。スタッフIDは注文の割当欄に表示する名前です。例として、ユーザー名 b、スタッフID b を登録できます。スタッフは専用画面で自分に割り当てられた注文だけ確認できます。
- **管理者追加** — 同じ画面で権限を「管理者」にし、ユーザー名とパスワードを登録します。スタッフIDは不要です。
- **利用停止・再開** — 対象者の「利用停止にする」を押すと、そのアカウントのログインを無効にします。スタッフの未完了注文は未割当に戻り、完了履歴は残ります。「利用を再開」で復帰できます。最後の有効な管理者は利用停止にできません。
- **ログアウト** — 画面右上からログアウトできます。変更後のパスワードは安全な場所に控えてください。

利用者のパスワードはハッシュ化して保存します。管理画面で現在のパスワードを見ることはできません。忘れた場合は管理者が新しいパスワードを設定します。スタッフ一覧の追加・削減は「アカウント管理」で行います。
